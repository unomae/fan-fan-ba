# E1 — Popup 與設定狀態摘要測試規格文件
**版本：** v1.0
**涵蓋維度：** 正向主流程 / 替代流程 / 負向流程 / 邊界測試 / 權限驗證 / 狀態轉換 / RWD

---

## TC-E1-001 Popup 顯示目前模型與 readiness

**維度：** 正向主流程 / 狀態轉換
**前置條件：** 已儲存一組測試 Key 與模型設定。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 從 Edge／Chrome 工具列開啟 Popup。
2. 比對目前模型、provider、API Key、TTS 與 Obsidian 摘要。
3. 關閉後重新開啟。

### 預期結果
- 摘要與 Options 一致；重新開啟不閃現舊狀態或重複元件。

### 失敗定義
- 模型／readiness 錯誤、秘密明文顯示、Popup 空白或無法再次開啟。

---

## TC-E1-002 Popup 快速切換模型

**維度：** 替代流程 / 狀態轉換
**前置條件：** 三個 provider 均有 dummy 或測試設定。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 依序選擇三個模型，每次關閉再重開 Popup。
2. 回到 Options 與網頁選字工具列確認模型。

### 預期結果
- 最後選擇持久化；Popup、Options 與實際請求使用同一模型。

### 失敗定義
- 顯示已切換但未保存、provider 狀態錯置或舊選擇覆蓋新選擇。

## TC-E1-003 缺設定與完整設定入口

**維度：** 負向流程 / 權限驗證
**前置條件：** 所有 Key、TTS 與 Obsidian 設定皆空。
**測試裝置：** 雙端

### 測試步驟
1. 開啟 Popup 並檢查缺少狀態。
2. 點「完整設定」。

### 預期結果
- 清楚顯示尚未設定，不誤稱可用；設定頁在正確 extension context 開啟。

### 失敗定義
- 缺 Key 被標為正常、直接發送請求、入口失效或開到錯誤擴充功能 ID。

---

## TC-E1-004 舊設定、快速連點與 Popup 壽命

**維度：** 邊界測試
**前置條件：** 準備未知舊模型 ID 與部分損毀 storage。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 開啟 Popup，快速連點模型與完整設定。
2. 在 storage 慢速／失敗時關閉並重開。

### 預期結果
- 未知模型安全 normalize；只有最後一次操作生效；無未捕捉錯誤。

### 失敗定義
- Popup 卡死、重複開頁、顯示 `undefined` 或損毀設定造成白屏。

## TC-E1-005 Popup 375px 與實際工具列尺寸

**維度：** RWD
**前置條件：** 以實際 extension popup 與 375px direct page 各測一次。
**測試裝置：** 行動 375px

### 測試步驟
1. 檢查卡片、三個模型、三個摘要與底部入口。
2. 使用鍵盤與觸控順序巡覽所有控制。

### 預期結果
- 固定寬度內容完整、無橫向裁切；焦點順序與視覺順序一致。

### 失敗定義
- 底部入口不可見、卡片超寬、焦點陷阱或文字互相重疊。
