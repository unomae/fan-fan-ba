# E2 — Welcome 與首次使用導引測試規格文件
**版本：** v1.0
**涵蓋維度：** 正向主流程 / 替代流程 / 負向流程 / 邊界測試 / 權限驗證 / 狀態轉換 / RWD

---

## TC-E2-001 首次安裝顯示完整三步導引

**維度：** 正向主流程 / 狀態轉換
**前置條件：** 乾淨 browser profile；首次載入 v1.9.9。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 載入擴充功能並觀察 Welcome 是否只開啟一次。
2. 閱讀 API Key、選字與結果／Obsidian 三步驟。
3. 點「前往設定 API Key」。

### 預期結果
- 內容、版本能力與實際 UI 一致；設定按鈕開啟正確 Options。

### 失敗定義
- Welcome 未開、重複開啟、說明過期或設定入口錯誤。

---

## TC-E2-002 稍後再說與重新進入

**維度：** 替代流程
**前置條件：** Welcome 已開啟。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 點「稍後再說」，確認分頁行為。
2. 直接開啟 `welcome.html` 再次閱讀並前往設定。

### 預期結果
- 稍後不強迫設定、不改動 Key；深層連結仍可正常使用。

### 失敗定義
- 自動建立秘密／設定、關閉錯誤分頁或再次進入白屏。

---

## TC-E2-003 外部連結與 extension 權限邊界

**維度：** 負向流程 / 權限驗證
**前置條件：** 離線或阻擋外部網路；無登入狀態。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 檢查 Groq、隱私權政策與 GitHub 連結目的地。
2. 離線開啟外部申請連結，再返回 Welcome。

### 預期結果
- 不自動送出資料、不要求不必要權限；外部失敗不影響 Welcome。

### 失敗定義
- URL 被竄改、帶入本機秘密、外部錯誤使擴充功能頁崩潰。

---

## TC-E2-004 重複事件與內容邊界

**維度：** 邊界測試
**前置條件：** 模擬 install／update 事件、舊設定與多視窗。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 重載擴充功能、開多個 Welcome，再快速點兩個底部按鈕。
2. 在舊版已有設定的 profile 模擬 update。

### 預期結果
- install 與 update 行為符合規格；不重複建立無限分頁；一次只採納一個動作。

### 失敗定義
- 更新也強制 onboarding、開啟分頁風暴或競態導向錯頁。

---

## TC-E2-005 行動版 Welcome

**維度：** RWD
**前置條件：** viewport 375px。
**測試裝置：** 行動 375px

### 測試步驟
1. 從標題捲到三步驟、兩個底部按鈕與 footer。
2. 檢查長 provider 說明與外部連結。

### 預期結果
- 卡片單欄排列；按鈕可觸控；無水平捲動或固定元素遮擋。

### 失敗定義
- 步驟順序混亂、文字裁切、按鈕超出畫面或 footer 不可達。
