# B4 — 備份還原測試規格文件
**版本：** v1.0
**涵蓋維度：** 正向主流程 / 替代流程 / 負向流程 / 邊界測試 / 權限驗證 / 狀態轉換 / RWD

---

## TC-B4-001 一般設定 JSON round-trip

**維度：** 正向主流程 / 狀態轉換
**前置條件：** 已設定非預設模型、語言與 Obsidian；不勾選 API Keys。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 匯出設定檔並檢查 schema、版本與內容。
2. 變更本機設定後匯入原檔。
3. 重新載入 Options、Popup 與網頁功能。

### 預期結果
- 一般設定完整還原；匯出檔不含任何 Key；所有頁面狀態一致。

### 失敗定義
- Key 明文出現、欄位遺失、未知欄位被套用或還原後狀態不同步。

---

## TC-B4-002 加密 Key 與單字本替代備份

**維度：** 替代流程
**前置條件：** 使用 dummy Key、8 字以上測試密碼與單字資料。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 勾選 API Keys，確認警告後匯出並以正確密碼匯入。
2. 分別匯出單字本 JSON 與 XLSX，使用 Excel／Sheets 開啟 XLSX。

### 預期結果
- Key 僅以加密內容存在且正確還原；密碼不被保存。
- JSON 可完整還原；XLSX 欄位可讀且不作為還原格式。

### 失敗定義
- 明文秘密、錯誤密碼也成功、XLSX 無法開啟或 JSON 資料不完整。

---

## TC-B4-003 錯誤檔案、密碼與匯入權限

**維度：** 負向流程 / 權限驗證
**前置條件：** 準備錯誤密碼、非翻翻吧 JSON、損毀 JSON 與唯讀檔案。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 逐一選取並嘗試匯入。
2. 匯入前後比較本機設定與單字資料。

### 預期結果
- 每種失敗有明確原因；任何失敗都不部分覆寫現有資料。

### 失敗定義
- 靜默失敗、錯誤檔被接受、現有資料被清空或錯誤訊息暴露秘密。

---

## TC-B4-004 惡意與極限備份內容

**維度：** 邊界測試
**前置條件：** 準備 `__proto__`、XSS、`=cmd`、重複單字及 >10MB 檔案。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 匯入惡意／大型 JSON，驗證白名單與大小限制。
2. 匯出含公式前綴的 XLSX。
3. 重複匯入同一單字本並比較 merge 結果。

### 預期結果
- 惡意鍵被忽略、>10MB 明確拒絕、公式以純文字開啟。
- 重複資料保留較高遇到次數，不產生 prototype pollution。

### 失敗定義
- 執行公式／腳本、瀏覽器卡死、資料翻倍或全域物件被污染。

---

## TC-B4-005 行動版備份還原頁

**維度：** RWD
**前置條件：** viewport 375px；準備小型測試檔。
**測試裝置：** 行動 375px

### 測試步驟
1. 操作勾選、密碼欄、匯出與檔案選擇器。
2. 捲動至單字本與安全提醒區。

### 預期結果
- 所有控制可見可按；長說明與檔名可換行；不誤觸相鄰按鈕。

### 失敗定義
- 檔案選擇器無法開啟、按鈕重疊或固定列遮住安全提醒。
