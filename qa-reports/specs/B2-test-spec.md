# B2 — 語言與朗讀測試規格文件
**版本：** v1.0
**涵蓋維度：** 正向主流程 / 替代流程 / 負向流程 / 邊界測試 / 權限驗證 / 狀態轉換 / RWD

## TC-B2-001 儲存語言、朗讀與高亮偏好

**維度：** 正向主流程 / 狀態轉換
**前置條件：** Options 已開啟；單字本有資料。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 修改目標語言、解釋語言、朗讀語音與單字高亮。
2. 儲存、重新載入，再執行翻譯／解釋與單字朗讀。

### 預期結果
- 所有偏好持久化；輸出語言、語音與高亮行為符合設定。

### 失敗定義
- 重新載入後回預設、各功能使用不同語言，或高亮狀態未同步。

## TC-B2-002 瀏覽器內建 TTS 替代路徑

**維度：** 替代流程
**前置條件：** Google Cloud TTS Key 留空；系統有可用語音。
**測試裝置：** 雙端

### 測試步驟
1. 選擇自動偵測與跟隨翻譯語言，各朗讀中英文單字。
2. 在不同頁面重複朗讀並中止前一次播放。

### 預期結果
- 無 Cloud Key 時使用瀏覽器語音；語言選擇合理且可停止／切換。

### 失敗定義
- 無聲無提示、重疊播放、語音語言錯置或錯誤要求 Cloud Key。

---

## TC-B2-003 無效 TTS Key 與語音權限

**維度：** 負向流程 / 權限驗證
**前置條件：** 無效測試 Key；模擬網路拒絕或語音不可用。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 儲存無效 Key 並測試連線。
2. 觸發朗讀，拒絕或移除可用語音。

### 預期結果
- 顯示可行動錯誤；不洩漏 Key；可安全 fallback 或明確告知無法朗讀。

### 失敗定義
- 未捕捉錯誤、Key 出現在訊息／log、無限 loading 或整個結果卡失效。

---

## TC-B2-004 語系與特殊內容邊界

**維度：** 邊界測試
**前置條件：** 可測中文、日文、RTL、emoji、數字與混合語句。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 對各內容組合執行翻譯、解釋、朗讀與高亮。
2. 快速切換語言設定並連續儲存。

### 預期結果
- 文字方向、語音與輸出不亂碼；最後一次有效設定勝出。

### 失敗定義
- RTL 版面破裂、語音崩潰、舊設定覆蓋新設定或高亮誤標 UI。

---

## TC-B2-005 行動版語言與朗讀頁

**維度：** RWD
**前置條件：** viewport 375px。
**測試裝置：** 行動 375px

### 測試步驟
1. 操作四個選單、TTS Key 欄與眼睛按鈕。
2. 開啟虛擬鍵盤、捲到底部並儲存。

### 預期結果
- 標籤與說明不重疊；選單、欄位與固定按鈕完整可用。

### 失敗定義
- 橫向溢出、控制被裁切、虛擬鍵盤遮擋或誤顯示 Key。
