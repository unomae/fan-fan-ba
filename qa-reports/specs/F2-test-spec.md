**版本：** v1.0
**涵蓋維度：** 正向主流程 / 替代流程 / 負向流程 / 邊界測試 / 權限驗證 / 狀態轉換 / RWD

## TC-F2-001 浮球啟動全文翻譯與模式切換

**維度：** 正向主流程 / 狀態轉換
**前置條件：** 全文翻譯模型 Key 可用；一般長文頁。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 展開浮球並點擊「全文翻譯 Beta」。
2. 等待翻譯完成，切換雙語／譯文／原文模式。
3. 測試複製譯文、複製雙語與定位原文。

### 預期結果
- 進度、成功／失敗數與模式狀態一致；段落配對不錯位。
- 切換模式不重送已完成段落。

### 失敗定義
- 面板不可見、段落遺失／重複、模式內容不一致或複製錯誤。

## TC-F2-002 Alt+T 單段翻譯與續翻

**維度：** 替代流程
**前置條件：** 一般長文頁；全文翻譯模型 Key 可用。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 游標停在段落或選取段落後按 Alt+T。
2. 對同一段再次按 Alt+T。
3. 再由浮球進入全文翻譯，確認既有段落被沿用。

### 預期結果
- 首次翻譯該段；再次觸發定位既有譯文，不重複請求。
- 全文流程可接續且保留前後文語境。

### 失敗定義
- 重複翻譯、段落錯配、快捷鍵無回饋或全文流程重置既有結果。

## TC-F2-003 缺 Key、站點停用與敏感網域

**維度：** 負向流程 / 權限驗證 / 狀態轉換
**前置條件：** 無全文翻譯 Key；另準備一般頁與 denylist 登入頁。
**測試裝置：** 雙端

### 測試步驟
1. 在一般頁啟動全文翻譯。
2. 由浮球點「在此網站停用」，重新整理並再嘗試選字。
3. 開啟 denylist 登入頁。

### 預期結果
- 缺 Key 時不送請求並引導設定。
- 停用後該站不再注入；其他站不受影響；敏感網域永不注入。

### 失敗定義
- 停用狀態未保存、作用到錯誤網域，或敏感頁仍可啟動翻譯。

## TC-F2-004 超長頁、局部失敗與重試

**維度：** 邊界測試
**前置條件：** 含 100+ 段、程式碼、表格、iframe 與動態內容的測試頁。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 啟動全文翻譯，模擬慢速、429、網路中斷與單段失敗。
2. 點擊「重試此段」，在執行中捲動並新增動態段落。
3. 驗證程式碼、表單與翻翻吧自身 UI 是否被錯翻。

### 預期結果
- 局部失敗不拖垮全頁；重試只處理該段，計數正確。
- 非文章內容與擴充功能 UI 不被翻譯。

### 失敗定義
- 無限 loading、整批重送、失敗計數錯誤、DOM 損壞或記憶體明顯失控。

## TC-F2-005 行動版浮球與全文面板

**維度：** RWD
**前置條件：** viewport 375px；一般文章頁。
**測試裝置：** 行動 375px

### 測試步驟
1. 展開浮球，操作四個主入口。
2. 開啟全文翻譯面板並切換模式、捲動與關閉。

### 預期結果
- 浮球不與瀏覽器邊緣衝突；選單、面板與主要按鈕可見可按。

### 失敗定義
- 控制超出畫面、無法捲動／關閉，或面板永久遮住原文。
