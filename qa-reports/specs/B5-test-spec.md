# B5 — 雲端同步測試規格文件
**版本：** v1.0
**涵蓋維度：** 正向主流程 / 替代流程 / 負向流程 / 邊界測試 / 權限驗證 / 狀態轉換 / RWD
**人工 gate：** OAuth 登入、上傳與下載會改動 Google Drive appData，Phase 0-C 需使用者授權。

---

## TC-B5-001 Google 登入、上傳與下載

**維度：** 正向主流程 / 狀態轉換
**前置條件：** 專用 QA Google 帳號；Phase 0-C 已建立 session。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 登入 Google，確認狀態與同步範圍。
2. 上傳這台設定，在另一個乾淨 profile 下載。
3. 比較模型、語言、朗讀與 Obsidian 設定。

### 預期結果
- 狀態、時間與版本更新；一般設定一致；Key、單字本、歷史不被同步。

### 失敗定義
- OAuth 失敗無提示、同步方向相反、秘密／單字本進入雲端或資料不一致。

## TC-B5-002 Native Auth 與 Web Auth fallback

**維度：** 替代流程
**前置條件：** Chrome Native Client 與 Edge Web Auth 測試設定可用。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 在 Chrome 使用 native auth 完成登入。
2. 在 Edge 使用 Web Auth fallback 完成登入。
3. 驗證 redirect URI、state 與最終帳號。

### 預期結果
- 兩條路徑都只取得 `drive.appdata` scope；state 驗證成功且回到 Options。

### 失敗定義
- scope 過大、redirect／state 不符仍接受、登入錯帳號或 callback 卡死。

## TC-B5-003 未登入、過期 token 與權限拒絕

**維度：** 負向流程 / 權限驗證
**前置條件：** 未登入、撤銷授權、過期 token、離線狀態。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 嘗試上傳與下載。
2. 登入流程中拒絕授權，再測 token 過期與離線。

### 預期結果
- 未授權不執行同步；錯誤可恢復且不清除本機設定。

### 失敗定義
- 無登入仍顯示成功、無限重試、洩漏 token 或破壞本機資料。

---

## TC-B5-004 覆寫衝突與版本邊界

**維度：** 邊界測試
**前置條件：** 雲端與本機各有不同版本／修改時間的測試設定。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 連點上傳／下載，測試慢網路、429、5xx 與中途關頁。
2. 測試未知欄位、舊 schema、空檔與損毀雲端檔。
3. 驗證覆寫確認文案與最後狀態。

### 預期結果
- 方向與覆寫風險清楚；僅白名單設定生效；失敗不留下半套資料。

### 失敗定義
- 無確認即覆寫、舊回應覆蓋新狀態、秘密被同步或本機設定部分損毀。

---

## TC-B5-005 行動版雲端同步頁

**維度：** RWD
**前置條件：** viewport 375px；未登入。
**測試裝置：** 行動 375px

### 測試步驟
1. 閱讀同步摘要與範圍，操作登入入口但不完成外部授權。
2. 展開進階設定並捲動所有按鈕。

### 預期結果
- 狀態列、長 redirect URI 與四個動作按鈕不溢出且順序清楚。

### 失敗定義
- 長字串撐破版面、危險按鈕誤觸或主要警告不可見。
