# B6 — 隱私、診斷與功能說明測試規格文件
**版本：** v1.0
**涵蓋維度：** 正向主流程 / 替代流程 / 負向流程 / 邊界測試 / 權限驗證 / 狀態轉換 / RWD

---

## TC-B6-001 本機診斷計數與自檢

**維度：** 正向主流程 / 狀態轉換
**前置條件：** API Key 可用；診斷計數為已知基準。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 各執行翻譯、解釋、優化、單段與全文翻譯。
2. 開啟隱私頁，比對動作計數、版本、模型與高亮狀態。

### 預期結果
- 每個成功／失敗事件按定義累加；自檢內容與實際設定一致。

### 失敗定義
- 漏記／重複計數、顯示舊版本或 readiness 與實際 Key 不符。

---

## TC-B6-002 缺 Key 與補回 Key 的替代狀態

**維度：** 替代流程
**前置條件：** 目前模型 Key 可移除並使用 dummy 測試 Key補回。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 清空目前模型 Key並查看自檢。
2. 補回測試 Key、儲存並重新查看。

### 預期結果
- 自檢由「需要處理」轉為可用；未發送測試請求時不誤稱已驗證連線。

### 失敗定義
- 狀態不更新、把格式存在當作連線成功，或顯示 Key 內容。

---

## TC-B6-003 清除診斷資料與儲存權限

**維度：** 負向流程 / 權限驗證 / 狀態轉換
**前置條件：** 有診斷資料；保留其他設定與單字本快照。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 點清除診斷資料並確認結果。
2. 重新載入並比較 API Key、一般設定、單字本與歷史。
3. 模擬 storage 寫入失敗。

### 預期結果
- 只清除診斷摘要；其他資料完全不變；寫入失敗有明確提示。

### 失敗定義
- 清除範圍過大、未清除、靜默失敗或影響使用權限。

---

## TC-B6-004 隱私邊界與無 telemetry

**維度：** 邊界測試 / 權限驗證
**前置條件：** Network 與 storage 可觀察；準備含敏感字串的 dummy 選取內容。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 執行各功能並檢查 Network、local／sync storage 與 console。
2. 驗證診斷摘要不含選取文字、URL、內容、Key 或 token。

### 預期結果
- 除使用者選定的 AI／Google 服務外無外連；診斷只含本機計數與非敏感狀態。

### 失敗定義
- 任意 telemetry、內容／URL／秘密落入診斷或未宣告網路請求。

## TC-B6-005 行動版隱私與診斷頁

**維度：** RWD
**前置條件：** viewport 375px；診斷卡有多筆狀態。
**測試裝置：** 行動 375px

### 測試步驟
1. 捲動所有說明、自檢卡與清除按鈕。
2. 測試長模型名稱與多位數計數。

### 預期結果
- 卡片、狀態與警告完整換行；清除按鈕不與固定操作列重疊。

### 失敗定義
- 內容被裁切、資訊層級混亂或危險操作在小螢幕上容易誤觸。
