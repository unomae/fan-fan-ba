# F1 — 網頁注入、選字工具列與結果卡測試規格文件
**版本：** v1.0
**涵蓋維度：** 正向主流程 / 替代流程 / 負向流程 / 邊界測試 / 權限驗證 / 狀態轉換 / RWD

---

## TC-F1-001 選字後完成翻譯、解釋與優化

**維度：** 正向主流程 / 狀態轉換
**前置條件：** 已載入 v1.9.9；至少一組對應模型 API Key 可用；Read Frog 已停用。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 開啟一般 HTTPS 文章頁，依序選取單字、句子與一段文字。
2. 分別點擊「翻譯」「解釋」「優化」。
3. 觀察串流結果卡、模型標示、複製與關閉控制。

### 預期結果
- 工具列只出現一組；結果逐步顯示且最後完成，不重複送出同一請求。
- 三種操作的標題、內容與診斷計數正確切換。

### 失敗定義
- 工具列未出現、操作錯置、結果卡不可見、串流中斷未提示或計數錯誤。

## TC-F1-002 iframe 與主頁的替代選字路徑

**維度：** 替代流程
**前置條件：** 開啟含同源與跨來源 iframe 的長文頁。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 在主頁選字並完成一次翻譯。
2. 在可互動 iframe 內選字並完成一次翻譯。
3. 檢查主頁與 iframe 的浮球及結果卡數量。

### 預期結果
- 主頁與 iframe 選字都可觸發工具列；浮球只在 top frame 顯示一顆。

### 失敗定義
- iframe 無法翻譯、出現多顆浮球，或結果顯示到錯誤 frame。

## TC-F1-003 缺 Key、敏感頁與敏感欄位保護

**維度：** 負向流程 / 權限驗證
**前置條件：** 清空目前模型 Key；另準備登入頁與密碼欄位。
**測試裝置：** 雙端

### 測試步驟
1. 在一般頁選字並點擊翻譯。
2. 開啟 manifest denylist 登入頁，確認注入狀態。
3. 在一般頁的 password／敏感輸入欄位選字。

### 預期結果
- 缺 Key 時提供可行動提示，不送出 API 請求。
- denylist 頁不注入；敏感欄位不顯示工具列或外洩內容。

### 失敗定義
- 無 Key 仍送出請求、敏感頁出現浮球，或敏感文字進入結果卡／log。

## TC-F1-004 空白、超長與惡意選取內容

**維度：** 邊界測試
**前置條件：** 一般測試頁可編輯並含特殊字元。
**測試裝置：** 桌機 1920px

### 測試步驟
1. 測試空白、換行、emoji、RTL、HTML／Markdown、`<script>` 與超長段落。
2. 快速連點同一操作兩次，再於串流中切換選取內容。
3. 檢查 DOM、console 與請求數。

### 預期結果
- 空白不送出；內容以純文字安全呈現；超長輸入有明確處理。
- 不執行腳本、不產生重複卡片或失去 request correlation。

### 失敗定義
- XSS、卡死、未處理例外、重複請求或舊結果覆蓋新結果。

## TC-F1-005 行動版工具列與結果卡

**維度：** RWD
**前置條件：** viewport 375px；API Key 可用。
**測試裝置：** 行動 375px

### 測試步驟
1. 在頁面上方、中央、底部與左右邊界選字。
2. 開啟工具列與結果卡，捲動、釘住、複製後關閉。

### 預期結果
- 工具列與卡片不超出 viewport、不遮住主要控制，可觸控且捲動正常。

### 失敗定義
- 水平捲動、控制被裁切、卡片無法關閉或定位離開可視區。
