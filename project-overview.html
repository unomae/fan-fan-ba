開發者地圖

入口與設定

  • manifest.json：權限、content scripts、background、popup、options。
  • popup.html / popup.js：工具列 popup。
  • options.html / options.js：完整設定頁、備份、Cloud Sync、診斷。
  • welcome.html / welcome.js：首次安裝 onboarding。

網頁內功能

  • content/toolbar.js：選字後浮出工具列。
  • content/result-card.js：翻譯、解釋、優化結果卡。
  • content/floating-ball.js：常駐浮球與閱讀入口。
  • content/page-translator-*.js：整頁 / 單段翻譯。

資料與共用工具

  • background.js：AI API、streaming、TTS、訊息入口、prompt 圍欄。
  • models.js：模型、語言、provider、migration。
  • storage.js：API Key、設定與本機診斷。
  • vocabulary-store.js / vocabulary-backup.js：單字本 IndexedDB、JSON、XLSX。
  • cloud-sync.js：Google Drive appData 同步與 OAuth state。

架構流程

選字翻譯流程

1. 使用者選字content/main.js 監聽 selection。
2. 工具列浮出toolbar.js 定位翻譯 / 解釋 / 優化。
3. 發送 requestcontent script 透過 runtime message / port 找 background。
4. AI 回應background.js 分流 Gemini / Groq / OpenRouter。
5. 結果渲染result-card.js 顯示並支援收藏、朗讀、Obsidian。

整頁 / 單段翻譯流程

1. 浮球啟動floating-ball.js 提供閱讀入口。
2. 收集段落page-translator-collector.js 避開 nav、button、editable。
3. 建立 pair原文與譯文用 pair id 對應。
4. 渲染卡片page-translator-renderer.js 做雙語 / 譯文 / 原文模式。
5. 面板控制停止、還原、續翻、定位原文、複製譯文。

資料與隱私

存在本機

  • API Key：chrome.storage.local，不跟 Chrome 帳號同步。
  • 單字本：extension-owned IndexedDB，保留 chrome.storage.local fallback / migration mirror。
  • 診斷摘要：只存功能使用次數、錯誤數、版本與設定狀態。

可能送出到外部服務

  • 使用者選取或要求翻譯的文字，會送到使用者選擇的 AI provider。
  • Cloud Sync 只同步一般設定到 Google Drive appData。
  • 不送完整 URL、不送瀏覽歷史、不送原文 / 譯文給自家 server，因為沒有自家 server。
修改隱私、storage、Cloud Sync 或診斷時，要同步檢查 privacy-policy.html、STORE-SUBMISSION.md、MANUAL-QA.md，避免程式行為與商店揭露不一致。

更新規則

功能有變時

  • 先更新本頁的「功能狀態」與「後續計劃」。
  • 如果新增 content script 或調整載入順序，要更新「架構流程」。
  • 如果改 storage、Cloud Sync、API Key、prompt 邊界或 telemetry 邊界，要更新「資料與隱私」與「資安健檢」。

驗證有變時

  • 自動測試結果寫在「測試與發布」。
  • 真瀏覽器 QA 結果回填 MANUAL-QA.md，摘要再寫回本頁。
  • Chrome Web Store 送審只在打磨完成後進行，不提前宣稱已上架。
Content script / CSS 修改後，只 reload 擴充功能不會重新注入已開啟分頁；必須刷新目標網頁才會看到新程式碼。
