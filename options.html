        備份還原

        設定檔

        模型、語言、術語表與自訂動作；換裝置或重裝時用。

        匯出與匯入加密備份都要用；忘記密碼就無法還原 API Key。

        匯入會取代目前的自訂動作清單。

        單字本

        JSON 可完整還原，CSV 給試算表看。匯入是合併，不會覆蓋既有單字。

        自動快照：保留最近 2 天

        每天最多留一份、共兩份（約可回到 24–48 小時前），逾 30 天自動清除。還原採合併，只補回缺少的單字，不會蓋掉快照之後的新增與複習進度。快照只存在這台裝置的瀏覽器，不上傳雲端，不能取代 JSON 匯出。

        雲端同步

        同步一般設定與術語表，不含 API Key、單字本與查詢紀錄。

        僅 Edge 等非 Chrome 瀏覽器需要。
