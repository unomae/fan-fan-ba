翻翻吧 — 隱私權政策

最後更新：2026 年 4 月 · 版本 1.2.x

📌 重點摘要：翻翻吧不收集、不儲存任何使用者個人資料。所有 API Key 僅存於您的裝置本地端，選取的文字僅傳送至您自行設定的 AI API，不經過任何第三方伺服器中轉或留存。

資料收集

翻翻吧不收集任何使用者個人識別資料，包括：

  • 不收集姓名、電子郵件或帳號資訊
  • 不收集瀏覽歷史或網頁 URL
  • 不記錄使用者選取的文字內容
  • 不進行任何形式的使用行為追蹤或分析

資料使用方式

翻翻吧僅使用以下資料來提供核心功能：

資料 用途 儲存位置
API Key（Gemini / Groq / OpenRouter / TTS） 呼叫使用者自選的 AI 服務 僅存於 chrome.storage.sync（本地裝置）
選取的文字 傳送至 AI API 取得翻譯 / 解釋 / 優化結果 不儲存，僅在請求期間傳輸，完成即丟棄
最近 5 筆查詢紀錄 顯示歷史紀錄供快速回顧 僅存於 chrome.storage.local（本地裝置）
偏好設定（模型選擇、Obsidian Vault） 記住使用者設定 僅存於 chrome.storage.sync（本地裝置）

第三方服務

根據使用者選擇的模型，翻翻吧會將選取文字直接傳送至對應的 AI API：

  • Google Gemini API（隱私權政策）
  • Groq API（隱私權政策）
  • OpenRouter API（隱私權政策）
  • Google Cloud Text-to-Speech（隱私權政策）— 選填功能

上述服務均由使用者自行申請 API Key 並直接使用，翻翻吧開發者不持有也無法存取任何通訊內容。

資料安全

  • API Key 僅儲存於瀏覽器本地端（chrome.storage.sync），不會傳送至任何翻翻吧伺服器（翻翻吧沒有伺服器）
  • 所有 AI API 請求直接從您的瀏覽器發出，不經任何中間伺服器代理
  • 擴充功能原始碼公開於 GitHub，可自行稽核

權限說明

權限 用途
storage 儲存 API Key、模型設定、查詢歷史（本地端）
<all_urls>（content script） 在任意網頁注入工具列，偵測文字選取事件
API host permissions 允許直接呼叫 Gemini / Groq / OpenRouter / TTS API
